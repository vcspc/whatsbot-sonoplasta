Manual de Instalação em VPS

Guia interativo passo a passo para instalar, configurar e manter o WhatsBot Sonoplasta funcionando 24 horas por dia em ambiente de produção.

⚠️
Requisito Crítico: Node.js 22.5.0 ou superior
O WhatsBot utiliza o banco de dados nativo node:sqlite, que só existe a partir do Node.js 22. Versões como Node 18 ou Node 20 não funcionarão.
Etapa 1

Conectar na VPS e Atualizar Pacotes

Acesse o servidor via SSH, sincronize os repositórios e acerte o fuso horário oficial de Brasília.

terminal (ssh)
# Acesse o servidor remoto ssh root@SEU_IP_DA_VPS # Atualize os pacotes do sistema operacional sudo apt update && sudo apt upgrade -y # Instale os utilitários básicos sudo apt install -y curl wget git build-essential ufw software-properties-common # Defina o fuso horário para garantir agendamento correto de lembretes e cultos sudo timedatectl set-timezone America/Sao_Paulo
Etapa 2

Criar Memória Swap de 2 GB (Prevenção OOM)

O Chromium do Playwright necessita de memória em picos. A Swap evita que o processo do bot seja finalizado abruptamente em VPSs de 1GB ou 2GB de RAM.

terminal
# Cria o arquivo de swap de 2GB sudo fallocate -l 2G /swapfile sudo chmod 600 /swapfile sudo mkswap /swapfile sudo swapon /swapfile # Torna permanente após reiniciar a VPS echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab # Confirma que a swap está ativa free -h
Etapa 3

Instalar Node.js 22 LTS e PM2

Adiciona o repositório NodeSource v22.x e instala globalmente o gerenciador PM2.

terminal
# Instala o repositório oficial do Node 22 LTS curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - sudo apt install -y nodejs # Valida as versões node -v # Deve exibir v22.x.x npm -v # Instala o PM2 para gerenciamento contínuo em segundo plano sudo npm install -g pm2
Etapa 4

Clonar o Repositório e Instalar Pacotes

Cria a pasta do projeto no servidor e baixa o código-fonte.

terminal
# Cria e ajusta permissões da pasta sudo mkdir -p /var/www/whatsbot-soplasta sudo chown -R $USER:$USER /var/www/whatsbot-soplasta cd /var/www/whatsbot-soplasta # Clona o repositório do projeto git clone https://github.com/SEU_USUARIO/whatsbot-soplasta.git . # Instala as dependências Node npm install --omit=dev
Etapa 5

Instalar Playwright Chromium e Bibliotecas do Linux

Essencial para extração automática de títulos de vídeos do YouTube no WhatsApp.

terminal
# Baixa o navegador Chromium do Playwright npx playwright install chromium # Instala as dependências de sistema Linux (libnss3, libasound2, etc.) sudo npx playwright install-deps chromium
Etapa 6

Configurar o Arquivo .env

Copie o arquivo de exemplo e defina suas chaves de API e credenciais de login.

terminal
cp .env.example .env nano .env
exemplo de .env na VPS
PORT=3000 GEMINI_API_KEY=sua_chave_do_google_gemini SONOPLASTA_PHONE=5511999998888 BOT_NAME=WhatsBot Sonoplasta TIMEZONE=America/Sao_Paulo REMINDER_TIME=09:00 # Desative o túnel Ngrok ao utilizar Nginx com domínio próprio NGROK_ENABLED=false # Credenciais de acesso ao Painel Web (ALTERE PARA UMA SENHA SEGURA) ADMIN_USER=admin ADMIN_PASSWORD=SuaSenhaForteAqui123!
Etapa 7

Iniciar o Bot 24/7 com PM2

Garante que a aplicação continue rodando após fechar a janela SSH e reinicie automaticamente no boot.

terminal
# Inicia o processo utilizando o arquivo de ecossistema pm2 start ecosystem.config.cjs # Configura auto-start no boot do servidor pm2 startup # (Execute o comando sudo exibido no terminal se solicitado) # Salva a lista de processos ativos pm2 save
Etapa 8

Configurar Nginx e SSL Gratuito (HTTPS)

Permite acessar o painel de forma segura através do seu domínio (ex: bot.suaigreja.com.br).

terminal
# Instala Nginx e Certbot sudo apt install -y nginx certbot python3-certbot-nginx # Cria o arquivo de configuração do site sudo nano /etc/nginx/sites-available/whatsbot
/etc/nginx/sites-available/whatsbot
server { listen 80; server_name bot.suaigreja.com.br; client_max_body_size 20M; location / { proxy_pass http://127.0.0.1:3000; proxy_http_version 1.1; proxy_set_header Upgrade $http_upgrade; proxy_set_header Connection 'upgrade'; proxy_set_header Host $host; proxy_cache_bypass $http_upgrade; proxy_set_header X-Real-IP $remote_addr; proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; proxy_set_header X-Forwarded-Proto $scheme; } }
ativar e gerar SSL
# Ativa o site e reinicia o Nginx sudo ln -s /etc/nginx/sites-available/whatsbot /etc/nginx/sites-enabled/ sudo nginx -t sudo systemctl reload nginx # Gera o certificado HTTPS com renovação automática sudo certbot --nginx -d bot.suaigreja.com.br
Etapa 9

Ativar o Firewall (UFW)

Protege a VPS permitindo apenas tráfego SSH e Web HTTP/HTTPS.

terminal
sudo ufw allow OpenSSH sudo ufw allow 'Nginx Full' sudo ufw enable sudo ufw status
Etapa 10

Conectar o WhatsApp

Abra o painel web ou os logs do PM2 para ler o QR Code de autenticação do Baileys.

  • Acesse seu painel no navegador: https://bot.suaigreja.com.br
  • Faça login com seu usuário e senha definidos no .env.
  • Clique no botão de status do WhatsApp no canto superior direito.
  • No seu celular, abra WhatsApp > Aparelhos conectados > Conectar um aparelho e aponte para o QR Code.
  • Você também pode visualizar o QR Code via terminal com: pm2 logs whatsbot --lines 100
